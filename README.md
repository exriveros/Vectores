# Vectores
## Programación para Excel de vectores basado en VBA usando RK4.

- El archivo trayectorias gravitacionales genera la trayectoria de dos cuerpos en el espacio utilizando Runge-Kutta, tomando la ecuación de la Ley Gravitacional de Isaac Newton.

- _Cohete.xlms presenta un cohete con un tanque de combustible que se consume con respecto al tiempo disminuyendo la masa hasta terminarlo, presentando velocidad vs tiempo y posición vs tiempo.

- Tiro Parabolico.xlsm presenta tres gráficas, Posición x, Posición y, Posición en 2D, del tiro parabólico en el vacío (sin fricción o pérdida de energía).

- ParacaidistaBaumgartner.xlsm presenta la grafica de velocidad vs tiempo, solución RK, variando el coeficiente de fricción con el aire calculada mediante interpolación polinomial segmentada (SPline).
