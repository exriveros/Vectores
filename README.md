# Vectores
Programación para Excel de vectores basado en Github.
El archivo trayectorias gravitacionales genera la trayectoria de dos cuerpos en el espacio utilizando Runge-Kutta, tomando la ecuación de la Ley Gravitacional de Isaac Newton.
_Cohete.xlms presenta un cohete con un tanque de combustible que se consume con respecto al tiempo disminuyendo la masa hasta terminarlo, presentando velocidad vs tiempo y posición vs tiempo.
